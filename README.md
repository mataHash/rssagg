A minimal rss aggregator API and worker

## Dependencies
- postgresql >= ^18
- goose >= ^3.27.3

### installation
#### postgresql
 - see [postgres official documentation](https://www.postgresql.org/download/) for more information
 - check also your package manager for availability

##### example with arch based linux distros
- getting the db engine and the oficial cli client
```bash
$ sudo pacman -S --noconfirm postgresql
```
- configuring the db engine
```
# mkdir /usr/local/pgsql
# chown postgres /usr/local/pgsql
# su postgres
postgres$ initdb -D /usr/local/pgsql/data
```
- starting the server
```
# systemctl start postgresql.service
```
- create an user
```bash
postgres$ createuser -P -S -R -d ***{USER}*** &&
postgres$ su ***USER***
$ createdb rssagg #create the db
```
see [postgresql documentation chapter 18](www.postgresql.org/docs/current/creating-cluster.html)
also see [archlinux documentation on postgres](https://wiki.archlinux.org/title/PostgreSQL)

#### goose
```bash
$ go install github.com/pressly/goose/v3/cmd/goose@latest
$ goose -version # to check if installed correctly
```

## .env.example
```txt
PORT={8080}
DB_URL={postgres://USERNAME:PASSWORD@localhost:5432/rssagg?sslmode=disable}
```
- copy this to a file named .env

> [!CAUTION]
> Please remember to change the USERNAME and PASWORD according to the ones you've made before

## Installation
```bash
$ git clone https://github.com/mata-codes/rssagg # clone the repo
$ cd rssagg # move to the repo
$ go mod tidy # install dependencies
$ cd sql/schema
$ goose postgres $(awk -F= '/postgres/{print $2}' ../../.env) up
$ go build && ./rssagg
```
> the API is running!!!!!!!!!!!!
## Usage
use any http client of your choice

### examples with curl

> [!CAUTION]
> Make sure you've installed curl and jq
#### create an user
```bash
$ curl -s -X POST http://localhost:8000/v1/users \
-H "Content-Type: application/json" \
-d '{"name":"user3"}' | jq '.'
```
#### get users

```bash
$ curl -s -X GET http://localhost:8000/v1/users \
-H "Authorization: ApiKey ***{apikey generated by the user}***"| jq "."
```

#### create feeds

```bash
$ curl -s -X POST http://localhost:8000/v1/feeds \
-H "Content-Type: application/json" \
-H "Authorization: ApiKey ***{apikey generated by the user}***" \
-d '{"name": "lanes blog", "url": "https://wagslane.dev/index.xml"}' \
| jq '.'
```
#### get feeds
```bash
$ curl -s -X GET  http://localhost:8000/v1/feeds \
| jq '.'
```

#### create feed following relationship
- this enpoint creates the relationship between an user and a feed
```bash
$ curl -s -X POST http://localhost:8000/v1/feed_follows \
-H "Content-Type: application/json" \
-H "Authorization: ApiKey ***{apikey generated by the user}***" \
-d '{ "feed_id": "***the id generated by the feed***"}' \
| jq '.'
```

#### get feed following relationships
```bash
$ curl -s -X GET http://localhost:8000/v1/feed_follows \
-H "Authorization: ApiKey ***{apikey generated by the user}***" \
| jq '.'
```
#### get posts
```bash
$ curl -s -X GET http://localhost:8000/v1/posts \
| jq '.'
```
